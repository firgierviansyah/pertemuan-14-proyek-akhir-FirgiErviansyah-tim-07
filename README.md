## Deskripsi Proyek

Program Pengolah dan Analisis Nilai Siswa merupakan proyek sederhana berbasis Python yang dirancang untuk membantu guru atau pengajar dalam mengolah data nilai siswa.

Program ini dapat menerima data nama dan nilai siswa, melakukan validasi nilai, menghitung statistik sederhana, serta menentukan status ketuntasan siswa.

Proyek ini dibuat sebagai bagian dari kegiatan perancangan proyek pada mata kuliah Algoritma dan Pemrograman.

## Tujuan

1. Mempermudah proses pengolahan data nilai siswa.
2. Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
3. Menentukan status ketuntasan siswa.
4. Menampilkan hasil analisis nilai secara terstruktur.
5. Menerapkan konsep dasar algoritma dan pemrograman Python.

## Fitur Utama

- Input data nama dan nilai siswa.
- Validasi nilai pada rentang 0–100.
- Perhitungan rata-rata nilai.
- Pencarian nilai tertinggi dan terendah.
- Penentuan status tuntas atau belum tuntas.
- Tampilan rekapitulasi hasil pengolahan nilai.

## Teknologi yang Digunakan

- Bahasa pemrograman: Python.
- Editor kode: Visual Studio Code.
- Version control dan penyimpanan proyek: GitHub.

## Gambaran Cara Kerja

1. Pengguna memasukkan jumlah siswa.
2. Pengguna memasukkan nama dan nilai setiap siswa.
3. Program memeriksa validitas nilai.
4. Program mengolah data yang telah diterima.
5. Program menghitung statistik nilai kelas.
6. Program menentukan status ketuntasan siswa.
7. Program menampilkan hasil pengolahan.
